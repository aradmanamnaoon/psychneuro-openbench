Status: PRIVATE literature appraisal; not evidence of empirical findings. Publisher/standards pages reviewed; this is a targeted narrative source selection, not a systematic review. DOI and links identify publications, **not permission to use their datasets**. Code paths refer to separately inspected, unmerged W03/W04 review branches.
