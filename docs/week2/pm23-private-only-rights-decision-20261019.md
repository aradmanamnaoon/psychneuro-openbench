## Evidence, actual tests and present limitations

- `src/psychneuro/registry.py:validate_registry()` hard-codes `license=not-separately-specified` for the only permitted synthetic generator; replacing it with a public licence **fails validation** rather than turning public redistribution on. For six external-human records any attempt to elevate download/ingestion/enabled flags fails closed.
- The [existing targeted tests](../../tests/test_registry.py) include synthetic-source identity, rejection of unknown license, external flag escalation, invalid consent boundary and tampered source URL. Historical [GitHub Actions #39112127659](https://github.com/aradmanamnaoon/psychneuro-openbench/actions/runs/39112127659) ran `python -m pytest -q` with **336 passing tests per Python 3.11/3.12**, plus Ruff and mypy **at exact SHA `dd79565e07923b35db7a7f09e0724a8c0594158e`**; this decision is *documentation-only*, so no new code or exact-doc-head test is claimed.
- The private synthetic benchmark yields no valid population, causal, clinical, psychological, or human-generalization result. Trial rows sharing an invented participant are dependent; use group-disjoint splits and pre-response predictors as already implemented. A software guard does not confer legal release permission.
- The PM-23 W02 requested **dataset source/license/provenance/privacy register and an explicit synthetic-only fallback** are now complete and internally approved. Therefore the **PM-23 task deliverable may be recorded Verified Done**, **while [issue #9](https://github.com/aradmanamnaoon/psychneuro-openbench/issues/9) deliberately remains OPEN** for any future *public* generated-data redistribution decision. Do not close the issue or claim public rights cleared. This resolves the W02 *documentation/choice-of-fallback* gate, not the public-release/licensing dependency.
- If later distribution is proposed, the human rights holder must choose an appropriate data grant after verifying ownership and applicable restrictions. Only then should `registry.json`, generated dataset cards, export manifests and source validation be deliberately revised with negative tests. The owner’s general approval to *finish internal work* does **not** constitute a specific licence grant.
