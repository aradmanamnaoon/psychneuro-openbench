## Research question / protocol-style outline

**Question:** For a wholly fictional repeated-trial binary correctness task, does logistic regression (pre-response `difficulty` and `stimulus_condition` only) yield a different held-group balanced accuracy than a `DummyClassifier(strategy="prior")` under an integrity-verifiable and strictly grouped nested-CV workflow?

- **Data rights and units:** generate only original synthetic nonclinical records; independent partition unit = fictional participant, not row; registry `psychneuro-synthetic-v0` is the sole permitted source. No human behavior, brain imaging, health, participant consent, physiological measurements or clinical validity is claimed.
- **Precommitted method:** 36 fictional participants × 12 trials; RNG generator seed 73; source group-split seed 42; 3 outer GroupKFold for estimated model-selection evaluation, 2 inner GroupKFold for logistic C ∈ {0.1,1.0}, tied mean CV accuracy chooses stronger-regularized C=0.1; fit preprocessing inside fold; one sealed heldout test only after final inner train-only tuning. Compare dummy-prior on identical outer folds; prespecify all fold scores and class support. Reject any ineligible one-class fold; do not secretly change seeds.
- **Primary metric:** unitless balanced accuracy. Comparator: same-fold dummy-prior balanced accuracy. Report additional macro-F1 and class supports before any population-level claim; current W03 result only reports balanced accuracy. Do not treat individual trials as independent; no p-value, CI, causal claim or human-generalization estimate is currently calculated.
- **Negative controls:** synthetic participant train/test collision, duplicate row, selective per-participant dropped row, prohibited post-response predictor and altered provenance DAG must fail before claiming a valid report. `KFold` row-wise intentionally raises the leakage sentinel; `GroupKFold` does not.
- **Selection and inference caveat:** time-locked predictors and nested CV address *some* leakage, but retrospective iteration, cohort-size limitations, site/time confounding, multiple comparisons, class imbalance and sample-specific model validation remain. This is a software protocol, not an actual original neuroscience experiment.
- **Research ethics:** avoid public release of generated independent exports until explicit rights-holder licence approval; all six external OpenNeuro human entries stay disabled. No IRB determination is asserted for prospective recruitment because no people are recruited.
- **Scientific reporting rule:** report every eligible/ineligible run, source hash, group split hash, exact run SHA and software versions, no significance until a prespecified refit-aware inferential framework and adequate independent units are justified.
